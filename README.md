# Utkarsh Portfolio - GitHub Pages

This is a static single-page site ready to host on GitHub Pages.

## Files

- `index.html` - main webpage

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload this folder content (`index.html` and `README.md`) to the repository root.
3. Open repository **Settings** > **Pages**.
4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Save and wait for deployment.
6. Your site will be available at `https://<your-username>.github.io/<repo-name>/`.
